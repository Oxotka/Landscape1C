# Экспертная перепроверка зрелости по результатам опроса 2026

Черновик пакетов для кураторов. Цифры пересчитаны по финальному снимку основной
волны от 30 сентября 2026 года: 316 участников. Для инструментов, которых нет в
основной волне, сохранены отдельные июльские результаты (247 участников); источник
указан рядом с числом. Срезы двух этапов не складываются.

## Что именно проверяем

Опрос в целом подтверждает экспертную разметку. Медианная доля ответов «работал»:

- базовое — 77,8%;
- продвинутое — 46,8%;
- нишевое — 9,7%.

Ниже собраны только выбросы и пограничные случаи. Опрос не меняет метку
автоматически: «работал» означает опыт когда-либо, а зрелость учитывает также роль
инструмента, его актуальность и положение именно в экосистеме 1С.

Для ответа по каждой строке достаточно выбрать один вариант:

- **перенести** — предлагаемая новая метка верна;
- **оставить** — текущая метка точнее;
- **другая метка** — указать метку и коротко объяснить почему.

> «работали» означает долю ответивших, которые когда-либо работали с инструментом.

## Разработка

Для Матвея Серегина и Игоря Апресова.

> **Visual Studio Code (VSCode): продвинутое → базовое?** 84,6% работали
> (208 из 246), узнаваемость 95,9%. По использованию VS Code уже находится в
> середине базовой группы. Стал ли он обязательной частью современного рабочего
> набора 1С-разработчика?
>
> **git: продвинутое → базовое?** 77,6% работали (187 из 241), узнаваемость
> 95,9%. Можно ли сегодня считать владение git профессиональной базой, несмотря
> на то что часть команд продолжает использовать Хранилище 1С?
>
> **1С:Автоматизированная проверка конфигураций (АПК): нишевое → продвинутое?**
> 41,7% работали (35 из 84), узнаваемость 85,7%. Результат соответствует нижней
> половине продвинутой группы, а не типичному нишевому инструменту.
>
> **Claude Code: нишевое → продвинутое?** 45,8% работали (38 из 83),
> узнаваемость 91,6%; 92,1% оценивших готовы использовать снова. Инструмент новый,
> поэтому вопрос в том, уже стал ли он рабочим мейнстримом или пока остаётся
> ранним быстрорастущим выбором.
>
> **Codex: нишевое → продвинутое?** 32,2% работали (29 из 90), узнаваемость
> 84,4%. Сигнал слабее, чем у Claude Code, поэтому это кандидат для наблюдения,
> поскольку сигнал по финальному срезу слабее, чем у Claude Code.

## Администрирование и производительность

Для Евгения Акпаева.

> **Angie: продвинутое → нишевое?** 1,6% работали (1 из 62), узнаваемость
> 17,7%. По опросу инструмент пока явно не выглядит профессиональным мейнстримом.
>
> **Caddy: продвинутое → нишевое?** 6,3% работали (4 из 64), узнаваемость
> 25,0%.
>
> **Double Commander: продвинутое → нишевое?** 11,1% работали (7 из 63),
> узнаваемость 20,6%.
>
> **PerfExpert: продвинутое → нишевое?** 7,9% работали (5 из 63),
> узнаваемость 25,4%. Похоже на инструмент специализированной задачи.
>
> **1С:Тест-центр: продвинутое → нишевое?** 18,5% работали (44 из 238),
> узнаваемость 71,8%. Инструмент известен, но реальное применение заметно ниже
> основной продвинутой группы.
>
> **nginx: базовое → продвинутое?** 43,5% работали (27 из 62), узнаваемость
> 93,5% (июльский этап). Для администратора это распространённый инструмент, но
> соответствует ли он определению базы, которую обязан знать каждый специалист?
>
> **APDEX: базовое → продвинутое?** 56,5% работали (35 из 62), узнаваемость
> 93,5% (июльский этап). Метрика распространена, но связана с отдельной областью
> производительности и может быть профессиональным, а не начальным уровнем.

## Инфраструктура и интеграции

Для Дмитрия Абрамова.

> **Объектное хранилище S3: нишевое → продвинутое?** 36,2% работали
> (34 из 94), узнаваемость 64,9%. Достаточно ли S3 распространилось в проектах 1С,
> чтобы считать его зрелым профессиональным инструментом?
>
> **Telegram-бот: оставить нишевым?** 70,1% работали (61 из 87), узнаваемость
> 94,3%. Это самый сильный выброс среди нишевых, но высокая частота может отражать
> популярность одной специфической интеграционной задачи. Нужно подтвердить,
> сохраняем ли «нишевое» по смыслу или переносим в «продвинутое».

## Тестирование

Для Татьяны Головкиной и Александра Кунташова.

> **Allure: нишевое → продвинутое?** 35,7% работали (35 из 98), узнаваемость
> 63,3%; 91,4% оценивших готовы использовать снова. По применению и возврату
> выглядит зрелым рабочим инструментом.
>
> **1С:Тестировщик: продвинутое → нишевое?** 11,9% работали (13 из 109),
> хотя узнаваемость составляет 77,1%. Похоже на известный, но редко применяемый
> специализированный инструмент.
>
> **1С:Сценарное тестирование: оставить продвинутым или перенести в нишевое?**
> 21,3% работали (23 из 108), узнаваемость 80,6%. Результат находится на нижней
> границе продвинутой группы.
>
> **Vanessa-ADD: оставить нишевым?** 46,1% работали (41 из 89), узнаваемость
> 83,1%. Высокий накопленный опыт конфликтует с текущей меткой, но инструмент
> считается вытесненным Vanessa Automation. Подтвердите, что историческая
> распространённость не должна менять его актуальную зрелость.

## Аналитика и организация работы

Для Романа Данилова и Марии Серегиной.

> **Wiki репозитория: базовое → продвинутое?** 31,8% работали (75 из 236),
> узнаваемость 74,6% (июльский этап). Результат заметно ниже остальных базовых
> инструментов. Является ли wiki обязательной базовой практикой или одним из профессиональных
> способов вести знания?
>
> **YouTrack: продвинутое → нишевое?** 13,8% работали (40 из 290),
> узнаваемость 36,9%. Большой знаменатель делает сигнал устойчивым: в выборке 1С
> инструмент не выглядит широко применяемым мейнстримом.
>
> **Microsoft Power BI: нишевое → продвинутое?** 27,3% работали (18 из 66),
> узнаваемость 83,3%. Доступность в РФ размечается отдельно, поэтому здесь вопрос
> только о профессиональной распространённости и зрелости инструмента.
>
> **1С:СППР: оставить нишевым?** 35,8% работали (44 из 123), узнаваемость
> 86,2%, но готовы использовать снова только 52,3% оценивших. Нужно подтвердить,
> что специализация на крупных проектных задачах важнее высокой накопленной
> распространённости.
