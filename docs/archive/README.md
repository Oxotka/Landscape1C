# Архив документов

Материалы отражают состояние проекта на дату написания. Текущее устройство
описано в [ТЗ](../TZ.md), а принятые решения — в [журнале](../decisions/2026-survey.md).

- [Исходные вопросы экспертам](surveys/2026-expert-questions.md) — обсуждение перед пересмотром карты.
- [Сентябрьский журнал работы с опросом](surveys/2026-09-06-handoff.md) — история реализации витрины.
- [Сравнение июля и 6 сентября](surveys/2026-09-06-comparison.md) — два исторических снимка разных выборок.
- [Компетенции](competencies/README.md) — замороженный эксперимент с грейдами; исходные матрицы сохранены рядом.
- [Отдельный роадмап обучения](roadmap/README.md) — исследование, не текущий план разработки.
- [Интерфейсные изменения сентября](ui-review-main-2026-09-20.md) — журнал проведенного разбора интерфейса.

Архив не задает текущие команды запуска, пути к данным и очередность работ.
При возобновлении темы сначала проверьте ее по коду и перенесите принятое
решение в актуальную документацию.
