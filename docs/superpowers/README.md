# Спецификации и планы разработки

`specs/` содержит датированные описания решений, `plans/` — планы их реализации.
Это рабочий формат навыков автоматизации проекта, поэтому папка сохраняет имя
`superpowers`.

Существующие материалы относятся к напоминаниям бота, интеграции с MAX и баннеру
опроса в августе 2026 года. Текущее состояние этих возможностей проверяйте по
[ТЗ](../TZ.md); старый план сам по себе не означает, что работу нужно выполнять заново.
Новые файлы именуются `ГГГГ-ММ-ДД-тема.md`.
