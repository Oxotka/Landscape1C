# Документация проекта

Начните с [ТЗ](TZ.md): оно описывает текущее состояние проекта и принятые
архитектурные решения. Правила разметки инструментов — в [методологии](METHODOLOGY.md).

## Где что лежит

| Папка или файл | Назначение |
|---|---|
| `TZ.md` | Текущее устройство сайта, реализованные возможности и оставшиеся задачи |
| `METHODOLOGY.md` | Правила ролей, контекстов, зрелости и интерпретации опроса |
| `decisions/` | Принятые решения: дата, результат и основание |
| `surveys/<год>/` | Разбор опроса: выводы, расчеты и предложения по карте |
| `superpowers/` | Датированные спецификации и планы разработки |
| `archive/` | Исторические заметки, завершенные обсуждения и замороженные исследования |
| `assets/` | Иллюстрации документации; скриншоты находятся в `assets/screenshots/` |
| [`../editorial/`](../editorial/README.md) | Статьи, посты и заготовки для публикации |

## Как добавлять документы

1. Изменение действующего поведения отражайте в ТЗ или методологии.
2. Принятое решение записывайте в `decisions/`; исходные обсуждения храните в архиве.
3. Разбор нового опроса размещайте в `surveys/<год>/`, данные — в предусмотренных источниках приложения и архиве агрегатов.
4. Статьи и посты размещайте в `editorial/articles/` и `editorial/posts/`. Указывайте статус: черновик, готово к публикации или опубликовано со ссылкой.
5. Исторический материал переносите в тематическую папку `archive/`, отмечайте дату и обновляйте ссылки на него. Старые команды из архива не являются инструкциями для текущей версии.

В именах новых файлов используйте тему и год или дату, если документ относится
к конкретному событию. Переименование сопровождайте исправлением относительных ссылок.
