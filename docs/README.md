# Документация проекта

Актуальное состояние — на 15 октября 2026 года. Для анализа карты и опроса
используйте документы из первого списка; исторические записи фиксируют состояние
на указанную дату и могут содержать отмененные планы и старые пути к файлам.

- [Инструкции по вкладу](../CONTRIBUTING.md) — карточки, исправления и проверки.
- [Бот](../bot/README.md) — команды, сбор ответов, локальные агрегаты и публикация.
- [Исходники агрегатов](../data/surveys/2026/README.md) — назначение архивов и подготовка `app/survey2026.js`.
