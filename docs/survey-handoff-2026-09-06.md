# Продолжение работы над публичными результатами опроса

Состояние на 6 сентября 2026. Пользователь посмотрел локальную единую витрину
и ответил: «О, выглядит норм». Затем попросил сохранить контекст для другой
сессии. Реализация сохранена в рабочей папке, коммита и публикации в этой
сессии не было. Следующий этап — подготовка публичного варианта; само одобрение
локального вида не является поручением немедленно публиковать.

## Принятые решения

- Оставляем существующую страницу `app/survey2026.html`, опрос продолжается.
- Верхнее приглашение участвовать и кнопки Telegram/MAX показываем всегда,
  независимо от происхождения результатов ниже. Запланированная отсечка — 1 октября.
- Пользователь отверг переключатель «Основной / Предварительный опрос»:
  людям нужны все инструменты вместе, без изучения истории этапов.
- Квадрант, таблица, зона роста показывают объединенный набор инструментов.
  Для пересечений используем только текущие ответы; июль дополняет инструменты,
  отсутствующие в текущем наборе. Ответы одного инструмента из этапов НЕ складываем.
  При отсутствии ответов в выбранном сегменте не подменяем текущий источник июлем.
- Июльские инструменты отмечаем «Июль 2026» в таблице, подсказках и CSV.
- «Кто участвует сейчас» — участники, оценки, число инструментов и профиль
  только текущего опроса. Никакого суммарного числа участников двух этапов.
- Фильтры роли/уровня/контекста применяются к данным каждого источника.
  Совпадение количества участников не доказывает совпадение самих людей.
- Пользователь прямо попросил сохранить порог 3 ответа для процентов второго
  вопроса: встречал вопросы, почему инструменты отсутствуют. Реализация сохраняет
  SENT_MIN=3, MIN_N=10 (приглушение строки), QUAD_MIN=5 (допуск в квадрант).
  Поэтому «все инструменты» означает общий набор источников, а не отмену порогов
  квадранта. До 3 ответов процента второго вопроса нет.
- Уже опубликованные июльские метрики базовых инструментов на карточках сохраняем.

## Что реализовано

- `app/survey2026.html`: единая витрина доступна ТОЛЬКО локально через
  `?preview=1` или `?data=live`. Прежний адрес `?preview=1#results` тоже открывает
  новый вариант. Без параметров остается июльская витрина.
- `app/survey-merge.js`: функция mergeSurvey(current, previous); текущие инструменты
  имеют приоритет, исторические получают july=true. Индексы ячеек обеих выборок
  переводятся в общий словарь осей по названиям, исходные объекты не мутируются.
  Респонденты берутся только из current.
- По последней просьбе пользователя поясняющий абзац перед квадрантом удален.
  Пометки источника у инструментов и в CSV сохранены.
- В CSV инструментов и сегментов добавлен источник; CSV респондентов — текущий.
- Если локальный файл не загрузился, текущие данные обнуляются перед загрузкой,
  чтобы не показать июль как якобы текущий опрос.
- `tests/survey-merge.test.js`: проверка приоритета источников, отсутствия сложения,
  несовпадающего порядка осей, исторических значений осей и неизменности входов.
- Обновлены проверки текста в `tests/survey-landing.test.js` и `tests/survey-live.test.js`.
- ТЗ актуализировано, версии ассетов пересчитаны.

## Что остается перед публичной публикацией

1. Проверить свежие агрегаты и охват обоих ботов, обновить снимок.
2. Определить публичный файл текущих агрегатов и подключение без локальных флагов.
   Сейчас live-файл игнорируется Git и исключен из dist: простого push недостаточно.
   Сохранить отдельный июльский источник и существующие метрики карточек.
3. Согласовать публичные подписи/метаданные и документацию: они местами еще
   описывают только предварительный этап. В ТЗ/методологии есть старое общее
   правило 10 ответов, тогда как для витрины пользователь явно оставил 3.
4. Перед финалом проверить фильтры, подсказки и CSV на реальных данных, оба размера
   экрана, сборку и тесты. Тест с синтетическими данными уже проверяет пересчет осей.
5. Публиковать после соответствующего поручения: push в main автоматически
   деплоит landscape1c.ru. Пока пользователь просил только локальный просмотр.

Ранее обсуждали ограничения добровольной выборки, разные знаменатели,
«работал» не равно «использует сейчас», намерение использовать снова не равно
фактическому возврату, пропуск не равен «нет». Полная редактура этих подписей
не выполнялась. В тестовом тексте бота есть обещание «ответы в итоги не пойдут»;
не проверено, видели ли его июльские участники. Исторические результаты уже
публичны; не скрывать происхождение при будущей публикации единой витрины.
