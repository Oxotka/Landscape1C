# Материалы для публикации

Здесь хранятся авторские статьи и посты о ландшафте. Действующие правила и
устройство проекта описаны в [документации](../docs/README.md).

- `articles/` — статьи и лонгриды, в том числе для Инфостарта.
- `posts/` — посты и редакционные планы для социальных сетей.
- Готовые изображения и макеты промоматериалов находятся в `promo/` в корне проекта.

## Материалы

| Материал | Состояние |
|---|---|
| [Ландшафт: от карты к реальному использованию](articles/infostart-landscape-2026.md) | Черновик периода сбора; перед публикацией нужны актуальные цифры и формулировки |
| [Базовый стек разработчика 1С](articles/infostart-basic-stack-2026.md) | Черновик; тезисы и показатели требуют редакционной проверки |
| [Посты про опрос за 7–9 сентября](posts/survey-2026-09-07-09.md) | Сентябрьские заготовки; не актуальный план публикаций |

В начале новых материалов указывайте статус. После публикации добавляйте дату
и ссылку. Цифры сверяйте с `app/survey2026.js`, решения по инструментам — с
[журналом решений](../docs/decisions/2026-survey.md). Содержание черновиков
не заменяет принятые решения по карте.
