# Архив агрегатов опроса 2026

Эти файлы — исходные исторические снимки для воспроизводимости. Сайт их не читает.
Актуальный опубликованный набор для анализа и всех страниц — **`app/survey2026.js`**.

- `july.json`: июль, 247 участников, 33 инструмента.
- `september.json`: итоговый сентябрьский снимок от 30.09.2026, 316 участников,
  202 инструмента.

`node scripts/survey-publish.js` готовит `app/survey2026.js`: 215 инструментов,
из них 202 из сентябрьского снимка и 13 отсутствовавших в нем — из июльского.
Счетчики одного инструмента и число участников разных снимков не складываются.
У каждого инструмента явно задан `july`: `true` для июльского источника,
`false` для сентябрьского. Индексы сегментов приводятся к общим словарям.

Сборка `node scripts/build.js` также запускает подготовку данных.
Архив содержит только обезличенные агрегаты, без журналов ответов и идентификаторов.
